## Quick start

```bash
git clone https://github.com/AbdullahBakir97/Space-Shooter.git
cd Space-Shooter
python -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
